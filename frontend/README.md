# DApp, ví và dashboard

Quốc Anh phụ trách module này. Đọc [Policy V1](../docs/insurance-policy-v1.md) và [giao nhận tích hợp](../shared/README.md) để thống nhất điều khoản hiển thị, giá trị wei, trạng thái và mã giao dịch. Frontend dùng quote của `risk/` và ABI, chain ID, địa chỉ deploy từ `blockchain/`.

Dùng thư mục module này cho app, cấu hình mẫu và hướng dẫn chạy. Khi có code, ghi lệnh cài/chạy, thiết lập ví local, cách kết nối dịch vụ quote và ba kịch bản đúng giờ, trễ đủ ngưỡng và hủy. Lưu receipt hoặc link bằng chứng khi kiểm thử tích hợp.
