# Dữ liệu, ML, Graph và báo giá

Nguyên phụ trách module này. Dùng [Flight Delays 2015](https://www.kaggle.com/datasets/usdot/flight-delays) cho thực nghiệm chính và [repo Prashant](https://github.com/Prashant-4527/flight-delay-prediction) làm điểm tham khảo. Đọc [Policy V1](../docs/insurance-policy-v1.md) khi tạo nhãn. Ghi phiên bản dataset, commit tham khảo, feature có trước lúc mua, temporal split và kết quả chạy của nhóm.

Đặt mã pipeline và báo giá trong `src/`. Dùng `data/raw/`, `data/processed/` và `models/generated/` cho dữ liệu hoặc mô hình lưu tại máy. Đưa cấu hình và bảng tổng hợp đủ nhỏ lên Git kèm lệnh tái lập. Bàn giao báo giá ký, fixture và bảng metric/graph cho DApp theo [giao nhận tích hợp](../shared/README.md).
